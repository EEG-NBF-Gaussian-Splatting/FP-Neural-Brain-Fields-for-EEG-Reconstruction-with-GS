# FP-Neural-Brain-Fields-for-EEG-Reconstruction-with-GS

This project focuses on EEG signal reconstruction and interpolation using Neural Brain Fields combined with 3D Gaussian Splatting.

## Project Goals

- Reconstruct missing EEG channels
- Generate virtual electrodes
- Improve spatial interpolation
- Enable efficient 3D visualization of brain activity

## Repository Structure

- `src/` — source code
- `experiments/` — experiment scripts
- `notebooks/` — exploratory notebooks
- `reports/` — project reports and documentation
- `data/` — local data folder, not tracked by Git
